# 🌍 Global Contest Score Tracker

## 📌 Project Overview

Global Contest Score Tracker is a web-based application designed to track and manage competitive programming performance.

The application collects, stores, and displays coding contest information such as ratings, rankings, scores, and contest history in a centralized dashboard.

It helps users monitor their competitive programming progress and analyze their performance over time.

---

## 🎯 Project Objective

- Provide a centralized platform for tracking coding contest performance
- Store user contest records efficiently
- Display rankings and ratings in an organized format
- Generate performance reports
- Simplify competitive programming progress analysis

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to project folder:

```bash
cd Global-Contest-Score-Tracker
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
